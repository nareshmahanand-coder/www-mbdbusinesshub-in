Place your custom notification ringtone here as:

    national_anthem.mp3

Requirements:
- short (3-6 seconds recommended)
- 44.1 kHz, mono or stereo
- file name MUST be lowercase ASCII without spaces (use underscores)
- referenced from code as "national_anthem" (no extension)

After dropping the file, run:
    npm run build && npx cap sync android
then rebuild the APK/AAB.
